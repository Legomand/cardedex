# Bundled native typography

DM Sans (400, 500, 600, 700) and Outfit (500, 600, 700, 800) are the same
families/weights requested by the canonical web application's Google Fonts link.
These unmodified TrueType files were downloaded on 2026-10-14 from the URLs
returned by that Google Fonts stylesheet. Native staging substitutes fonts.css
for the remote stylesheet so fonts load without a connection. The web app keeps
its existing hosted stylesheet.

DM Sans and Outfit licence/copyright notices accompany the packaged fonts in
dmsans-OFL.txt and outfit-OFL.txt. Font file hashes are included in each generated
native-manifest.json.
